# ipmesctool

基于 Tauri 2、React 和 Rust 的电机配置与调试工具，串口协议对齐 GPMD_Code 的 `APP/uart_com.cpp`。

## 0.3.3

- 适配最新 UART 配置：新增单相绝对电流过流保护阈值，电流 PI 改为独立 d/q 四参数。
- 速度环辨识扫频电流移至“校准 → 校准参数”；过流保护位于“设备信息 → 电流保护”。
- 本次发布同时包含波形历史、测量和 CSV 导出功能，使用方式见下文。

## 串口交互

- 连接使用 460800 baud，先发送 `get_none` 停止遗留数据流，再执行 `get_config` 校验设备与配置格式。普通命令以 CRLF 结束，必须收到 `ok` 才确认成功；`error parameter/state/flash/internal/command` 会显示具体原因。下述数据流切换命令没有应答，仅确认主机已写出。
- 配置快照包含固件状态、uint32 设备 ID、单相过流保护阈值、Rs/Ld/Lq、电流/速度/位置环参数、速度环辨识扫频电流幅值及编码器配置。九行配置全部必需，读取等待末尾 `ok`，缺字段或非法保护阈值不会被当作成功。
- 配置写入仅允许 `Ready` 状态，固件自动写 Flash，无需独立保存。设备 ID 写入范围为 **0–2047**（标准 FDCAN ID），不是整个 uint32 范围。电流 PI 使用 `config_current_pi <d_kp> <d_ki> <q_kp> <q_ki>`，四个增益独立、均须为有限正数；界面保留解锁确认，保存后展示固件实际读回值，不再共用一组 d/q 增益。速度环辨识扫频电流 `config_speed_sweep_current <A>` 使用 q 轴正弦幅值，必须大于 0，入口为“校准 → 校准参数”。
- “设备信息 → 电流保护”设置 `config_current_limit <A>`：任一相电流绝对值超过该阈值会触发过流保护并进入 `Fault`，**不是电流给定的软限幅，也不是速度 PI 的 OutputMax**。阈值必须为有限正数。固件不强制扫频幅值与保护阈值的大小关系，设置时应考虑实际相电流。保存等待固件确认及配置读回；Flash 错误会显示失败，不伪造成功。
- 编码器支持 `AS5600`、`MT6701_IIC`、`MT6701_SPI`、`AS5047P`，方向 `CW/CCW`，极对数 1–255，偏移为电角度 rad。
- 控制支持速度（rpm）、累计机械位置（度）、q 轴电流（A）、停止，以及 `Fault` 状态下清除故障。界面选择 rad/s 或 rad 时会换算为固件所需单位。
- 校准启动的 `ok` 不代表完成；工具持续读取阶段、结果及失败阶段，直到终态报告结束。成功后由固件主循环自动保存参数；协议没有独立的保存结果应答。
- 串口控制台可以发送单行原始命令，并保留最新 5000 行 TX/RX。普通命令与应答串行处理；超时或普通应答接收丢行时关闭连接，避免迟到应答错配下一条命令。连续流不占用普通应答通道。

当前固件 UART 不提供母线电压设置、电流滤波设置或电机电气参数手动写入；这些入口与手动保存功能仍不提供。

## 波形图

在侧栏打开“波形图”，点击四个平铺的数据源按钮，再点击“开始采集”。采集中点击另一个源即可单击切换；停止或断连时只切换查看的源，不会自动开始采集。四种数据源互斥，并非同步采集：

| 模式 | 命令 | 帧格式 | 单位 |
|---|---|---|---|
| 三相电流 | `get_iabc` | `iabc:a,b,c` | A |
| DQ 轴电流 | `get_idq` | `idq:d,q` | A |
| 机械速度 | `get_speed` | `speed:给定,反馈` | rpm，界面可切换 rad/s |
| 累计机械位置 | `get_position` | `position:给定,反馈` | deg，界面可切换 rad |

- “停止采集”只发送 `get_none`，**不会停止电机**；停机仍使用底部 `Stop`。上述五个流控制命令都没有 `ok`，页面显示的是主机写出状态，不是固件确认；串口控制台发送这些命令也遵循同一规则。
- 固件最多按 1 kHz 节拍输出。横轴为本次连接的**主机单调接收时间**，不是设备采样时间；UART 带宽和调度会影响实际间隔。
- 显示时间窗仍为 **1/5/10 秒**，与历史保留长度独立。历史默认保留 **5 分钟**，可选 1/5/10/15 分钟；所有源按本次连接最新接收时间滚动淘汰旧点，保留完整采样值。延长只影响后续保留，不能恢复已淘汰数据。分块缓存避免每批复制全部历史，绘图只转换当前窗口的数据。
- “暂停查看”冻结当前源的历史快照，后台采集仍在继续，可拖动历史滑块；即使实时缓存继续淘汰旧点，快照也保持不变。“跟随最新”恢复实时查看。切换源会退出暂停；“清空全部波形”清除四种源和暂停视图，不停止采集。
- 悬停读取采样时间和各曲线数值；点击图形依次选择 A、B，显示 **Δt 和各曲线 Δ值**，第三次点击重新选 A，也可用方向键移动、回车选点。游标保存实际采样点，移出显示窗口后仍保留读数并提示超窗；可用“清除测量”重置。
- 每条曲线可独立隐藏；Y 轴可自动缩放或输入有限的最小/最大值后“应用固定 Y”，最小值必须小于最大值。窗口统计包含各曲线的最小值、最大值、均值、峰峰值，隐藏曲线仍参与统计。切换源、单位或新会话会重置测量及源相关轴设置。
- “导出 CSV…”打开原生保存对话框：可导出当前源全部历史（暂停时为冻结快照）、当前可见窗口，或所有源的实时历史。文件含 UTF-8 BOM、列名单位、原始行和完整精度数值；使用协议原始 **A / rpm / deg**，不随界面单位改变。所有源按主机接收时间合并为同一文件，不适用的信号列留空；取消保存不写文件。
- 断开连接停止采集，但**保留最后会话的历史**，仍可切源、暂停回看和导出；新连接开始时清空旧历史，不混合不同连接的时间轴。原生 `get_telemetry_state` 返回 `{sessionId,mode}`；遥测、模式和断连事件携带同一会话 ID，迟到的旧会话事件不会进入新历史或断开新连接。
- 后端待发队列最多 256 点、约每 33 ms 批量送往前端；消费不及时会淘汰最旧待发点，不影响普通命令应答，历史不能恢复串口或队列已丢失的样本。连接关闭前尽力发送 `get_none`。


协议回归测试覆盖九行配置完整性、过流阈值与独立 d/q 增益的数值/状态边界、旧二参数电流 PI 拒绝、校准终态与失败报告、控制状态限制、应答识别、四种波形帧解析及高频流与应答隔离。原生 Tauri + PTY 冒烟已验证配置写入/读回、Ready 限制、Flash 错误传播及后续事务恢复；PTY 模拟串口不能替代真实电机的过流保护、控制、波形时序与校准验收。
