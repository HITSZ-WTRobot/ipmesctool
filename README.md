# ipmesctool

基于 Tauri 2、React 和 Rust 的电机配置与调试工具，串口协议对齐 GPMD_Code 的 `APP/uart_com.cpp`。

## 0.3.4 · UART 指令同步

以当前固件 `APP/uart_com.cpp` 实际分派为准，与工具原先显式支持的 19 条命令比较：新增支持 **17 条**，现共 **36 条**；原命令无删除或改名。这里比较的是工具协议契约，不推断固件的提交历史。

| 新增命令 | 参数 / 应答与限制 |
|---|---|
| `config_flux_speed <rpm>` | 磁链辨识机械速度幅值，100–3000 rpm |
| `config_speed_filter <Hz>` / `config_current_filter <Hz>` / `config_speed_pll <Hz>` | 编码器速度滤波、电流滤波、编码器 PLL 自然频率；有限正数且不得使固件单精度系数溢出 |
| `config_hfi <voltage> <current_filter> <kp> <ki> <speed_filter>` | 电压 ≥ 0 V；两项滤波频率均为 (0, 2500) Hz；Kp/Ki 为有限正数 |
| `config_observer_flux <gamma> <kp> <ki>` | Gamma ∈ (0, 10¹²]，Kp ∈ (0, 10⁶]，Ki ∈ (0, 10⁸] |
| `config_observer_transition <low> <high>` | 电气 rpm；0 ≤ low < high ≤ 1000000 |
| `config_backup <0\|1>` | Ready 下切换运行时备份；启用要求 HFI 电压 > 0；**不写 Flash** |
| `hfi_enable` / `hfi_disable` | 启用仅限三种控制态，且须满足固件的备份/注入电压条件；禁用允许任意连接状态；均等待 `ok` |
| `get_hfi` / `get observer flux` / `get observer transition` | 单项配置查询：数据行后仍须等待 `ok`；控制台可直接使用 |
| `get_angle` / `get observer pos` / `get observer speed` | 三种新增连续流，**无 `ok`**，格式和单位见波形表 |
| `iap` | 仅 Ready；`ok` 后复位进入 Bootloader。工具直接释放串口供升级程序接管，不发送后续 `get_none` / `get_config`；未提供 Ymodem 镜像上传器 |

所有新增 `config_*` 命令都仅允许 Ready、校验参数并等待固件确认，成功后读回配置；除 `config_backup` 外均由固件持久化到 Flash。原始控制台与类型化 API 共用这些规则。

`get_config` 由原 9 个必需数据 tag 扩展到 **14 个 tag + 最终 `ok`**：新增 `fault`、`hfi`、`observer_flux`、`transition`、`backup`；`motor` 新增 `flux`（Wb）、`flux_speed`（机械 rpm），`speed_sweep` 新增 `speed_filter`、`current_filter`、`pll_frequency`（Hz）。缺少新增字段或读到非法值会报错，不填充旧版默认值。固件 UART 文档遗漏了实际输出的 `fault` / `backup`，此处按源码处理。

异步上报新增 `fault <flags>`（1=过流、2=编码器，可组合）及 `hfi_state <n>`：0=Bypass、1=Starting、2=Observing、3=VoltageLimit、4=Invalid。界面显示真实报告，命令确认不代表观测器已经收敛。校准新增 `flux_forward`、`flux_reverse`、`flux_stopping` 阶段和 `result magnet_flux=<值> Wb`，最终成功仍以报告结束分隔线为准。

入口：“校准 → 校准参数”提供磁链辨识速度和三项滤波/PLL；新增“观测器”页提供 HFI、磁链观测器、过渡区、运行时备份及 HFI 启停；设备信息显示磁链、故障旗标及 HFI 状态。磁链辨识会让电机双向旋转。

## 串口交互

- 连接使用 460800 baud，先发送 `get_none` 停止遗留数据流，再执行 `get_config` 校验设备与配置格式。普通命令以 CRLF 结束，必须收到 `ok` 才确认成功；`error parameter/state/flash/internal/command` 会显示具体原因。下述数据流切换命令没有应答，仅确认主机已写出。
- 配置快照包含固件状态/故障旗标、uint32 设备 ID、单相过流保护阈值、Rs/Ld/Lq/磁链及辨识速度、电流/速度/位置环参数、扫频电流与滤波/PLL、编码器、HFI、磁链观测器、过渡区和运行时备份。14 个配置 tag 全部必需，读取等待末尾 `ok`，缺字段或非法值不会被当作成功。
- 配置写入仅允许 `Ready` 状态；除运行时 `config_backup` 外，固件自动写 Flash，无需独立保存。设备 ID 写入范围为 **0–2047**（标准 FDCAN ID），不是整个 uint32 范围。电流 PI 使用 `config_current_pi <d_kp> <d_ki> <q_kp> <q_ki>`，四个增益独立、均须为有限正数；界面保留解锁确认，保存后展示固件实际读回值，不再共用一组 d/q 增益。速度环辨识扫频电流 `config_speed_sweep_current <A>` 使用 q 轴正弦幅值，必须大于 0，入口为“校准 → 校准参数”。
- “设备信息 → 电流保护”设置 `config_current_limit <A>`：任一相电流绝对值超过该阈值会触发过流保护并进入 `Fault`，**不是电流给定的软限幅，也不是速度 PI 的 OutputMax**。阈值必须为有限正数。固件不强制扫频幅值与保护阈值的大小关系，设置时应考虑实际相电流。保存等待固件确认及配置读回；Flash 错误会显示失败，不伪造成功。
- 编码器支持 `AS5600`、`MT6701_IIC`、`MT6701_SPI`、`AS5047P`，方向 `CW/CCW`，极对数 1–255，偏移为电角度 rad。
- 控制支持速度（rpm）、累计机械位置（度）、q 轴电流（A）、停止，以及 `Fault` 状态下清除故障。界面选择 rad/s 或 rad 时会换算为固件所需单位。
- 校准启动的 `ok` 不代表完成；工具持续读取阶段、结果及失败阶段，包含磁链正转、反转和停机，直到终态报告结束。成功后由固件主循环自动保存参数；协议没有独立的保存结果应答。
- 串口控制台可以发送单行原始命令，并保留最新 5000 行 TX/RX。普通命令与应答串行处理；超时或普通应答接收丢行时关闭连接，避免迟到应答错配下一条命令。连续流不占用普通应答通道。

当前固件 UART 不提供母线电压设置或 Rs/Ld/Lq/磁链手动写入；这些入口与手动保存功能仍不提供。电流/速度滤波与编码器 PLL 设置已支持，不再属于缺失功能。

## 波形图

在侧栏打开“波形图”，点击七个平铺的数据源按钮，再点击“开始采集”。采集中点击另一个源即可单击切换；停止或断连时只切换查看的源，不会自动开始采集。七种数据源互斥，并非同步采集：

| 模式 | 命令 | 帧格式 | 单位 |
|---|---|---|---|
| 三相电流 | `get_iabc` | `iabc:a,b,c` | A |
| DQ 轴电流 | `get_idq` | `idq:d,q` | A |
| 机械速度 | `get_speed` | `speed:给定,反馈` | rpm，界面可切换 rad/s |
| 累计机械位置 | `get_position` | `position:给定,反馈` | deg，界面可切换 rad |
| 电角度 | `get_angle` | `angle:编码器,观测器` | 电角度 deg |
| 观测器电角度 | `get observer pos` | `observer_pos:编码器,观测器` | 电角度 deg；当前固件数值与 `get_angle` 相同 |
| 观测器电气速度 | `get observer speed` | `observer_speed:编码器,观测器` | 电气 rpm，不按极对数换算 |

- “停止采集”只发送 `get_none`，**不会停止电机**；停机仍使用底部 `Stop`。七种采集选择加停止共八个流控制命令都没有 `ok`，页面显示的是主机写出状态，不是固件确认；串口控制台发送这些命令也遵循同一规则。新增电角度/电气速度保持协议单位，不受机械单位开关影响，也不按极对数换算。
- 固件最多按 1 kHz 节拍输出。横轴为本次连接的**主机单调接收时间**，不是设备采样时间；UART 带宽和调度会影响实际间隔。
- 显示时间窗仍为 **1/5/10 秒**，与历史保留长度独立。历史默认保留 **5 分钟**，可选 1/5/10/15 分钟；所有源按本次连接最新接收时间滚动淘汰旧点，保留完整采样值。延长只影响后续保留，不能恢复已淘汰数据。分块缓存避免每批复制全部历史，绘图只转换当前窗口的数据。
- “暂停查看”冻结当前源的历史快照，后台采集仍在继续，可拖动历史滑块；即使实时缓存继续淘汰旧点，快照也保持不变。“跟随最新”恢复实时查看。切换源会退出暂停；“清空全部波形”清除四种源和暂停视图，不停止采集。
- 悬停读取采样时间和各曲线数值；点击图形依次选择 A、B，显示 **Δt 和各曲线 Δ值**，第三次点击重新选 A，也可用方向键移动、回车选点。游标保存实际采样点，移出显示窗口后仍保留读数并提示超窗；可用“清除测量”重置。
- 每条曲线可独立隐藏；Y 轴可自动缩放或输入有限的最小/最大值后“应用固定 Y”，最小值必须小于最大值。窗口统计包含各曲线的最小值、最大值、均值、峰峰值，隐藏曲线仍参与统计。切换源、单位或新会话会重置测量及源相关轴设置。
- “导出 CSV…”打开原生保存对话框：可导出当前源全部历史（暂停时为冻结快照）、当前可见窗口，或所有源的实时历史。文件含 UTF-8 BOM、列名单位、原始行和完整精度数值；使用协议原始 **A / 机械 rpm / 机械 deg / 电角度 deg / 电气 rpm**，不随界面单位改变。18 列分别保留机械量和各电气量，不能混用；所有源按主机接收时间合并为同一文件，不适用的信号列留空；取消保存不写文件。
- 断开连接停止采集，但**保留最后会话的历史**，仍可切源、暂停回看和导出；新连接开始时清空旧历史，不混合不同连接的时间轴。原生 `get_telemetry_state` 返回 `{sessionId,mode}`；遥测、模式和断连事件携带同一会话 ID，迟到的旧会话事件不会进入新历史或断开新连接。
- 后端待发队列最多 256 点、约每 33 ms 批量送往前端；消费不及时会淘汰最旧待发点，不影响普通命令应答，历史不能恢复串口或队列已丢失的样本。普通连接关闭前尽力发送 `get_none`；IAP 确认后直接释放串口，不再发送任何应用指令。
